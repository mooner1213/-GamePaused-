# 옥상 중앙 착지와 우주 상승 엔딩

## 현재 동작

- 발판 번호 대신 실제 최상층 높이와 바로 아래 발판 높이를 찾는다. 바로 아래 층에서 점프하면 최상층의 좌우 범위 중앙으로 안내한다. 중앙에 빈 공간이 있으면 가장 가까운 옥상 발판 중앙으로 착지한다.
- 점프 세기와 기존 바라보는 방향에 관계없이 같은 지점에 착지하며, 옥상 착지에서 남은 예약 점프를 종료한다. 예상 잔상과 실제 이동은 같은 `PauseSimulation` 경로를 사용한다.
- 옥상에 실제로 착지한 뒤 ESC → 점프 키를 누르면 고정된 흰색 일시정지 문구를 향해 슬로우 어퍼컷을 한다.
- 문구 파괴 뒤에는 어퍼컷 03번 프레임(가장 높은 주먹)을 유지하고 계속 가속 상승한다. 옥상으로 돌아오지 않는다. 크레딧이 시작된 뒤에도 상승한다.
- 엔딩 카메라는 일반 카메라와 휠의 높이 제한을 넘어서 추적한다. 상승 속도가 커져도 주먹이 화면을 벗어나지 않도록 지연 거리를 제한한다.
- 15개 테마 씬과 MainScene에 고정된 우주 배경 면을 추가했다. Y 210~360에서 기존 석양과 어두운 대기가 혼합되고 이후 더 어두운 우주와 도트 별로 이어진다. 면의 범위는 Y 200~10,240이며 Y 10,000 화면에 여유를 둔다. 그 이상의 무한 배경은 이번 범위에 포함하지 않는다.

## Inspector

- 게임 관리자 → 이동 설정의 `옥상 직전 도약 · 중앙 착지`: 사용 여부, 도약 시간, 곡선 높이, 같은 층 허용 오차.
- 게임 관리자 → 엔딩 설정의 `문구 파괴 후 하늘 상승`: 초기 속도, 가속도, 크레딧 전 상승 시간.
- 카메라 → `엔딩 하늘 상승 추적`: 추적 부드러움.
- 하늘 배경 자식 `06 하늘에서 우주 · Y 210~10240` → `PauseSpaceBackdrop`: 우주 전환 높이와 우주 색. Transform에서 면 범위를 직접 편집할 수 있다.

## 검증

- Unity 6000.3.22f1 컴파일 후 Console 오류·경고 조회 0건.
- 모델 30조건: 5가지 발판 재질 × 3가지 점프 세기 × 양방향. 변경된 번호와 위치의 발판에서 옥상 중앙 착지, 잔여 예약 종료, 진행 중 예측 복제의 위치 오차 0.
- 실제 09번 씬을 Editor Play에서 자동 입력으로 검사: 100번 → 수작업 옥상 중앙 `(0, 174.8)` 착지 → ESC·점프 → 문구 충돌 → 크레딧 → Y 10,011까지 연속 상승. 충돌 후 968회 표본에서 03번 프레임 유지와 주먹 화면 내부 위치 확인.
- 같은 실행에서 재시작 후 엔딩·중앙 안내 상태 해제, 출발점 복귀, 크기 `(1,1,1)` 복구 확인.
- Y 200/280/390/1,000/10,000 월드 렌더링 확인. 실제 Play의 Y 10,000 상승 화면도 캡처했다.
- 16개 씬 저장 전후 기존 Transform·Tilemap·Collider 블록 비교: 우주 면을 연결하는 부모의 자식 참조 추가 외 기존 형상 변경 0건. 사용자가 직접 칠한 옥상과 발판 배치를 보존했다.
