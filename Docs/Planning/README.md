# 일시정지! · 게임 기획 요약

기준 문서: [게임 기획서 통합본 1.0](GameDesign_v1.0.pdf) · 2026-10-28 · 16쪽

2인 팀 프로젝트의 메인 기획 담당자가 구성한 게임 콘셉트와 규칙·스토리·UI 및 콘텐츠 방향을 정리합니다. 기획과 제작 전반에 AI를 활용하고 있으며 현재 게임은 개발 중입니다.

이 문서는 PDF를 웹에서 탐색하기 위한 요약입니다. 원본의 확정 방향과 설계 제안·조정 항목을 구분합니다.

## 1. 콘셉트와 대상

| 항목 | 기획 |
| --- | --- |
| 게임명 | 일시정지! · 가제 |
| 장르 | 2D 도트 등반 플랫포머 |
| 목표 플랫폼 | PC |
| 핵심 요소 | 시간 정지와 점프 사전 입력 및 벽 충돌 방향 전환 |
| 대상 경험 | 등반의 긴장감·성취감과 경로를 계획하는 재미 |
| 콘텐츠 | 메인 스토리와 업적으로 해금하는 추가 스테이지·코스튬 |

전반부에는 실시간 조작 부담을 낮추고 지형 분석과 점프 설계의 비중을 높입니다. 방향키를 없애고 벽 반사로 방향을 바꾸게 해 단순한 입력 안에서도 경로 선택이 필요하도록 설계합니다.

## 2. 핵심 플레이와 입력

관찰 → ESC 정지 → 점프 강도·순서 예약 → 정지 해제와 실행 → 결과 확인 → 다음 경로 설계의 흐름입니다.

| 상태 | Space | ESC |
| --- | --- | --- |
| 전반부 입력 대기 | 정지 상태에 들어간 뒤 입력 | 일시정지와 입력 상태 진입 |
| 전반부 정지 | 누름 시간에 따른 강도·순서 저장 | 정지 해제와 실행 |
| 예약 점프 재생 | 새 점프 추가 제한 | 정지·재개 |
| 배신 이후 | 누르고 놓아 직접 점프하는 방식 제안 | 정지 기능 사용 불가 |

점프 강도는 키를 누르는 압력이 아니라 **누르고 있는 시간**에 따라 정합니다.

### 연속 점프 실행 제안

각 점프의 강도를 저장한 뒤 착지 시 다음 예약 점프를 순서대로 실행합니다. 입력 사이의 쉬는 시간은 재생 간격으로 저장하지 않는 방식입니다.

남은 예약 점프가 있는 동안에도 정지와 재개는 가능하지만 새 명령을 추가하지 못하게 합니다. 공중 추가 도약과 구분하며 최소·최대 차지 시간과 이동 물리값은 테스트로 조정합니다.

## 3. 환경 기믹과 시간 규칙

| 요소 | 규칙과 역할 |
| --- | --- |
| 이동 | 걷기와 임의 방향 전환 없이 현재 방향으로 점프 |
| 벽 | 충돌 시 방향 반전과 남은 운동에 따른 반사 |
| 얼음 발판 | 미끄러짐과 벽 충돌을 경로 설계에 활용 |
| 이동형 발판 | 위치와 주기를 예측하며 일반 정지 규칙 적용 |
| 3초 파괴 발판 | 밟으면 타이머 시작. ESC로 정지해도 타이머 진행 |
| 구름 발판 | 착지 후 짧은 시간 안에 소멸하는 방식 제안 |

일반 움직임이 정지해도 **점프 입력 시간을 측정하는 처리와 입력 UI 및 예외 타이머는 계속 동작**해야 합니다.

구름 발판은 일시정지로 소멸을 막을 수 없게 하고 연속 점프를 미리 계획하도록 유도하는 제안입니다. 유지 시간은 조정 대상입니다. 후반부에는 ESC 없이 직접 점프로 통과할 수 있도록 간격과 배치를 재구성합니다.

## 4. 학습과 난이도 구성

| 구간 | 보조 궤도 | 학습·도전 목표 |
| --- | --- | --- |
| 극초반 | 전체 표시 | 넓은 발판에서 점프 강도와 연속 점프·벽 반사 학습 |
| 초반 | 점진적 축소 | 얼음과 경사·이동 발판 및 거리 판단 |
| 중반 | 표시 없음 | 3초 파괴·구름 발판에서 신속한 결정과 연속 점프 설계 |
| 후반 | 표시 없음 | 좁은 발판과 복합 기믹·연속 벽 반사 |
| 정상 직전 | 표시 없음 | 4회 연속 점프의 강도와 실행 시점 설계 |

추락하면 도달한 낮은 구간의 가이드 규칙을 적용합니다. 정상에서는 UI의 일시정지 글자를 캐릭터와 충돌 가능한 스토리 목표물로 연결합니다.

## 5. 스토리와 플레이 변화

<details>
<summary>메인 스토리와 결말 펼치기 · 스포일러</summary>

게임에 화가 난 플레이어가 책상과 키보드를 내려치자 자판들이 모니터 속으로 도망갑니다. 남아 있던 ESC는 도움을 요청하며 플레이어를 컴퓨터 속 성벽으로 안내합니다.

1. 플레이어는 ESC의 안내를 따라 일시정지 기능으로 성벽을 오릅니다.
2. 정상에서 일시정지를 파괴하면 ESC가 배신합니다.
3. 진행 상태를 저장한 뒤 게임이 강제로 종료되는 사건을 연출합니다.
4. 재실행하면 ESC를 사용할 수 없는 후반부로 이어집니다.
5. 구조와 음악이 바뀐 성벽을 다시 올라 ESC와 보스전을 치릅니다.
6. 마지막은 어퍼컷으로 ESC를 격파하고 크레딧으로 연결합니다.
7. 크레딧 뒤 2D 도트 현실에서 금이 간 모니터와 부서진 키보드를 확인합니다.

마지막 대사: “...모니터랑 키보드 다시사야지”

보스 패턴과 체력·피해 판정 및 별도 공격키 사용 여부는 후속 설계 대상입니다. 어퍼컷을 마지막 유효 점프 충돌 뒤의 마무리 연출로 연결하는 방식을 제안합니다.

### 재실행과 새 메인 시작의 차이

| 상황 | ESC | 유지·초기화 |
| --- | --- | --- |
| 메인 첫 시작 | 사용 가능 | 도입부터 진행 |
| 배신 사건 이후 재실행 | 사용 불가 | 저장된 후반부에서 재개 |
| 최종 결말 후 새 메인 시작 | 사용 가능 | 스토리 진행 초기화 |
| 2회차 이후 배신 장면 도달 | 사건 이후 사용 불가 | 기존과 같은 순서로 후반부 진행 |

최종 클리어 후의 재플레이는 규칙과 스테이지 흐름을 유지하고 일부 대사와 짧은 이벤트만 바꾸는 방향입니다. 업적과 해금 기록 및 클리어 이력은 보존합니다.

## 6. UI와 연출

| 요소 | 설계 방향 |
| --- | --- |
| 설정 | 우측 상단 버튼을 마우스로 열어 사운드·키·종료 설정 |
| 정지 화면 | 흑백과 옅은 반투명 오버레이. 지형 윤곽 유지 |
| 보조 궤도 | 초반 학습 지원 후 높이에 따라 축소·숨김 |
| 파괴 발판 게이지 | 발판 아래 남은 시간 표시. 정지 중에도 감소 |
| 정상의 글자 | 일시정지 UI를 충돌 가능한 이야기 목표로 연결 |
| 업적 알림 | 등반 화면을 크게 가리지 않는 짧은 안내 제안 |

점프 경로와 착지 지점의 시인성을 우선합니다. 정지 시 게임 음악·효과음을 멈추고 해제 시 재개하며 후반부는 음악 변주와 구조 변화로 분위기를 전환합니다. 최종 음원과 편곡 방향은 제작 과정에서 정합니다.

## 7. 업적과 콘텐츠 해금

| 조건 예시 | 보상 |
| --- | --- |
| 메인 스토리 최종 클리어 | 스테이지 탭 |
| 점프 300회 | ice 스테이지 |
| 100타일 이상 추락 | 낙하넥타이 |
| 메인 스토리 3분 내 클리어 | 왕관 |

위 수치는 기획 예시이며 최종값은 테스트로 조정합니다.

- 메인 클리어는 일시정지의 첫 파괴가 아니라 ESC 격파와 최종 결말까지 도달한 상태입니다.
- 개별 스테이지 조건을 먼저 달성하면 해금 기록을 보관하고 스테이지 탭이 열린 뒤 선택하게 합니다.
- 달성 조건과 진행도 및 획득 보상을 표시하고 보상 중복 지급을 방지합니다.
- 새 메인을 시작해도 업적과 스테이지·코스튬 해금을 유지합니다.

### 업적 판정 제안

- 점프 횟수는 실제 실행된 도약을 집계하는 기준으로 검토합니다.
- 추락 거리는 한 번의 연속 추락에서 최고점부터 최종 안착까지의 수직 낙차로 판정하는 방식을 제안합니다.
- 클리어 시간은 조작 가능한 전·후반 구간의 실제 경과시간을 합산하고 ESC 계획 시간도 포함하는 방식입니다. 로딩·컷신·크레딧·프로그램 종료 시간은 제외하고 재실행 시 집계를 이어갑니다.

## 8. 기획 검증 기준과 미확정 항목

다음은 **기획서의 확인 기준**이며 완료된 시험 결과 목록이 아닙니다.

| 대상 | 확인 기준 |
| --- | --- |
| 점프·벽 반사 | 같은 입력 시간의 일관된 도약과 충돌 후 방향 변화 |
| 사전 입력 | 예약 순서와 정지·재개 및 추가 입력 제한 |
| 궤도·발판 | 예측과 실제 결과의 차이 및 정지 중 예외 타이머 |
| 스토리 상태 | 배신 후 재실행 시 후반부 복귀와 새 메인 시작 시 ESC 복구 |
| 후반부·보스전 | ESC 없이 통과 가능한 배치와 결말 순서 |
| 업적·해금 | 조건 판정과 저장·중복 지급 방지 및 재시작 후 유지 |

### 후속 조정 대상

점프 차지 시간·이동 물리값과 구름 발판 시간·후반 캐릭터 외형·정상 글자의 유지 및 충돌 판정·보스 패턴·추가 스테이지 규칙·업적 수치와 보상·설정 메뉴 중 시간 처리는 후속 설계에서 확정합니다.

### 현재 자료 범위

원본 PDF에는 화면 삽입 자리가 있으며 최종 게임 이미지와 시연 자료는 준비 중입니다. 코드 기반의 기존 프로토타입 설명과 검증 자료는 [루트 README](../../README.md) 및 [개발 상세 기록](../DevelopmentNotes.md)에서 별도로 확인합니다.
