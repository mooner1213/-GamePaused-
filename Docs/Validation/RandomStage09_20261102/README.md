- 초반 4·6칸, 중반 4칸, 후반 2·4칸이며 일반·기름·금간·타이머를 혼합한다. 원래 바닥(0번)은 보존했다. 출발점은 검증 입력과 같은 `(-10, 0)`이다.

- 실제 물리 표면 수 111개 = 바닥 1 + 새 등반 발판 98 + 기존 옥상 구간 12. 옥상 구간들은 하나의 24m 옥상으로 이어진다.
- 기존 발판과 로프·바람·트램펄린 등 장치는 삭제하지 않고 `이전 발판과 장치 · 비활성 보관 20261102`에 보관했다. 검증 시안에 없는 장치가 경로를 바꾸지 않게 했다. 외벽 두 개는 유지했다.
- 성벽·배경·옥상의 기존 그림과 타일 내용·색·변환을 설치 전후 지문으로 비교하여 동일함을 확인했다. 설치를 다시 실행해도 씬 파일이 변경되지 않는다.

## 검증

`Install.json`: 저장된 새 발판 98개, 실제 표면 111개, 기존 환경 지문 동일.

`Runtime.json`: **Unity 6000.3.22f1 실제 Editor Play PASS**. 씬에서 만든 실제 PauseGame에 60Hz 검증 시계를 연결하고 ESC 녹화 → 누르기/떼기 → ESC 재생 순으로 입력했다. 검증 중 위치·속도·방향을 직접 바꾸거나 중간 초기화·치트 이동을 사용하지 않았다.

- 99회 도약, 25개 예약 묶음, 20회 외벽 반동.
- 순서대로 지정한 모든 등반 발판 방문 및 옥상 중앙 `(0, 174.8)` 착지.
- 금간 위 새 계획 금지, 기름 관성, 녹화 중 타이머 진행을 실제 게임 경로로 검사.
- 옥상에서 ESC와 점프 입력 → 슬로우 어퍼컷 → 문구 적중 → 하늘 상승 → 크레딧 확인.
- 게임 사건 및 Console 오류 0개.

`실제Play_엔딩.png`는 실제 GameView 캡처다. `실제씬_7m.png`, `실제씬_87m.png`, `실제씬_165m.png`는 적용한 저장 씬의 편집 화면 정지 렌더다. 두 증거의 범위를 구별한다.

`FinalEditor.json`: Play 종료, 컴파일 종료, 씬 비수정 상태, 검증용 리로드 잠금 해제. 새 Tilemap 98개·타이머 표시 6개와 재실행 시 파일 동일 확인.

`SceneScope.json`: 작업 시작 시점 대비 09번 파일만 변경, 나머지 15개 씬 SHA256 동일. `CommitAssetAudit.json`: 커밋 자산의 메타·GUID·제외 경로 검사 결과.
