# 옥상 포탈 제거

전체 16개 씬의 비활성 오브젝트까지 확인하여 마지막 출구를 제거했다. 09번에는 이미 없었고 다른 14개 테마와 MainScene에서 총 15개를 삭제했다.

`PauseGoalExitBuilder.Apply`는 기존 출구 제거만 수행하도록 수정했다. 생성 도구와 관련 검증의 기대값도 출구 0개로 변경했다. 포탈 그림 자산과 팔레트 자체는 삭제하지 않았다.

삭제 전후 실제 발판·외벽·장치 모델과 모든 Tilemap의 직렬화 데이터를 비교하여 변동이 없음을 확인했다. 현재 MainScene의 저장되지 않은 편집도 먼저 백업하고 저장한 다음 처리했다. 비교 갤러리의 16개 씬 렌더링도 갱신했다.

세부 결과: `Scenes.txt`. 엔딩은 정상 발판 착지 상태를 기준으로 하며 출구 오브젝트를 참조하지 않는다.

생성기의 정리 함수를 다시 호출해도 출구가 0개임을 확인했다. MainScene Editor Play 자동 입력 검사에서 포탈 0개 → 정상 착지 인정 → ESC·점프 → 문구 충돌 → 크레딧 → 어퍼컷 03번 유지·Y 477까지 상승을 확인했다(`Runtime.txt`). Console 컴파일/실행 오류 조회 0건. 검사를 끝내고 MainScene을 저장된 편집 상태로 돌려두었다. 새 빌드·기기 실행 검사는 하지 않았다.
