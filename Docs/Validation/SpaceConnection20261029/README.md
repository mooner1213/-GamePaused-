# 하늘에서 우주로 연속 연결

기존 우주 면이 카메라를 0.96 비율로 따라가는 하늘 레이어 아래에 있었다. 우주 전환 시작 높이 210m도 같이 이동하므로 실제 엔딩의 수백 m 높이에서 우주 면이 카메라보다 위에 머물렀다. Renderer 연결도 비어 있어 정지 상태 전달이 누락되어 있었다.

## 수정

- 15개 디자인 씬과 MainScene에서 우주 면만 시차 루트 밖의 맵 루트로 옮겼다. 월드 위치·하단 200m는 유지했다.
- Renderer 참조를 연결하고, 초기 연결 시 같은 오브젝트에서 복구할 수 있게 했다.
- 우주 표시 순서를 -50으로 지정했다. 하늘·구름·원경보다 앞, 성 내부와 플레이 오브젝트보다 뒤다. 210~360m에서 기존 배경 위에 자연스럽게 섞이며 그 위에서는 기존 하늘 끝이 드러나지 않는다.
- 우주 갱신을 PauseWorldView에서 독립적으로 캐시·호출한다. 카메라가 올라가도 우주 바닥과 별의 월드 좌표는 이동하지 않는다.
- 기존 면 끝에 가까워지면 위쪽 범위만 512m 단위로 확장한다. 재생 중 Y 10,000을 지나도 배경 면이 끝나지 않는다.

모든 발판·벽·장치 모델과 Tilemap 내용·색·변환은 적용 전후 비교에서 동일했다. 자세한 씬별 결과와 백업 경로는 `Scenes.txt`에 있다.

## 확인

`RenderedHeights.txt` 및 높이별 PNG는 저장된 MainScene에서 175/210/250/300/360/700/10,000m를 카메라로 렌더한 결과다. 석양에서 보라색 대기층과 별이 나타나는 우주로 이어진다.

`Runtime.txt`: 실제 MainScene Editor Play에서 옥상 → ESC·어퍼컷 → 문구 파괴 → 크레딧을 실행했다. 크레딧 약 9초 시점, 카메라 Y 483.97에서 월드 고정 우주 면과 정상 Renderer 연결을 확인했다. `엔딩크레딧_실제우주배경.png`는 이 화면의 실제 캡처다.

별도 높이 이동 검사에서 카메라 Y 10,000/10,500/20,000에 대해 우주 면 하단은 200으로 고정됐고 상단은 각각 10,952/11,464/20,680으로 확장됐다. 정지 흑백 1 → 재생 0 전환도 통과했다. 검증용 재로드 잠금은 해제하고 Play를 정지했다.

새 빌드·실기기 검증과 전체 스테이지 완주는 수행하지 않았다.
