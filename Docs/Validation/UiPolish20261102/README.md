# UI 70%와 초반 키 안내 · 2026-11-02

메인 씬과 실제 게임 진입 씬인 `Stage09_RGBKeyboard`의 UI를 수정했다. 맵·옥상·배경 그림과 엔딩의 타격 목표 중심은 보존했다.

## 변경

- 제목·버튼·슬라이더·확인창 등 UI 콘텐츠를 기존 크기의 **70%**로 축소했다. 배경·검은 메뉴·모달 차단 영역·페이드 막은 전체 화면을 그대로 채운다. Slider의 손잡이·채움은 부모와 함께 한 번만 축소한다.
- 메인 우측 상단에 트로피와 코스튬을 가로로 배치했다. 기존 투명 MenuSheet에 남아 있던 부품을 Sprite 자산으로 분리하여 사용했다. 새 그림 생성이나 원본 PNG 변경은 하지 않았다.
- 각각 클릭하면 `트로피는 아직 구현되지 않은 기능입니다.`, `코스튬은 아직 구현되지 않은 기능입니다.`를 표시하고 잠시 후 부드럽게 숨긴다.
- 09번의 높이·방향·최고 기록·재생 잔여 문구, 기존 하단 설명/예약/충전 패널, 정지 제목 아래의 누른 시간 설명을 숨겼다. 실제 점프 예약·잔상·타이머 발판의 월드 도트와 터치 조작 기능은 유지했다.
- 일반 ESC 예약 화면 상단은 제공받은 픽셀 일시정지 제목을 사용한다. 정상에 가까워졌을 때의 기존 흰색 고정 타격 문구는 별도 경로로 유지한다. 글자 크기는 축소하지만 중심과 충돌 좌표는 바꾸지 않았다.
- 좌측 하단 두 줄: `ESC 시간 정지 · 예약 재생`, `SPACE 정지 중 누르고 떼어 예약`. 최고 높이 **12m**부터 **1.25초** 동안 페이드아웃한다. 현재 높이가 아닌 최고 높이 기준이므로 추락해도 다시 나오지 않으며 새 게임에서 복원된다. 관리 메뉴와 엔딩에서는 키 안내를 숨긴다.

Inspector 조정 위치: 09번 `게임 관리 Canvas · 편집 가능`의 **PauseGameplayGuidance → 초반 키 안내**. `안내가 사라질 최고 높이(m)`, `사라지는 시간(초)`를 바꿀 수 있다. 기존 HUD로 비교하려면 PauseHud의 HUD 배치 설정 안 `픽셀 게임 화면만 표시`를 끈다. 기본 비활성 설정을 유지한 다른 디자인 씬에는 새 간소화 HUD를 강제하지 않았다.

## 검증과 증거

Unity **6000.3.22f1 실제 Editor Play**, UI 이벤트와 자동 입력 드라이버로 검사했다.

1. 메인 버튼과 트로피·코스튬의 실제 배율 `.7` 확인. GraphicRaycaster와 PointerClick으로 트로피 안내, 코스튬 안내 확인. `Main.json`, `Costume.json`.
2. 설정 Slider 배율 `.7` 확인. 관리 메뉴의 검은 패널 배율 `1`, 버튼 배율 `.7` 확인. `Settings.json`, `MenuScale.json`.
3. 시작점에서 안내 알파 `1`, 간소화 HUD 활성, ESC 예약 시 픽셀 제목 표시 확인. `Gameplay.json`, `Recording.json`.
4. 실제 8회 도약·2개 예약 묶음 후 **13.6m**에 도착. 안내 알파가 약 `.96 → .77 → .51 → .25 → 0`으로 변화하는 실제 프레임을 기록했다. `TutorialFade.json`, `Hidden.json`.
5. 이어서 총 **99회 도약·25개 예약 묶음**, 옥상 중앙 착지·어퍼컷 적중·크레딧까지 다시 통과했다. `RouteEarly.json`, `Route1~4.json`, `RouteFinal.json`, `Ending.json`. 게임 물리/정상 충돌 로직과 목표 중심은 변경하지 않았다.
6. 실제 `예` 버튼으로 재시작하고 최고 높이 `0`, 안내 알파 `1`, 숨김 해제 상태를 확인했다. `Restart.json`.
7. 지정 파일에 대한 별도 정적 리뷰에서 전체 패널 보존, 중복 축소 방지, 최고 높이 기반 숨김 유지, 재시작 복원과 엔딩 연결을 검토했다. 추락 후 재등장 방지는 최고 높이 불변·숨김 상태 유지 경로의 정적 검토 범위이며, 이번 기록에서 별도의 낙하 장면을 재생했다는 뜻은 아니다.
8. `SceneScope.json`: 기존 17개 씬 중 메인·09번만 변경, 다른 15개 씬 해시 동일. 09번 맵 루트 하위 1,325개 오브젝트의 3,955개 직렬화 문서가 작업 전 파일과 바이트 단위로 동일했다.

`01_Main70.png`~`10_RestartConfirmation70.png`는 실제 GameView 캡처다. Android 실기기·새 APK/Windows 실행 파일 빌드는 이번 UI 수정 범위에서 수행하지 않았다.

다시 실행: 편집기 메뉴 `일시정지/화면/UI 70%와 초반 키 안내 적용`. 이미 적용된 씬에는 다시 축소하지 않는다. 수작업 중인 씬은 저장하고 Play를 종료한 상태에서만 실행한다.
