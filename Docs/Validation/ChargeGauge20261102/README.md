# 머리 위 점프 충전 게이지 · 2026-11-02

09번 씬의 `게임 관리 Canvas · 편집 가능/머리 위 점프 충전 게이지`에 추가했다. 기존 도트 테두리와 금색 채움 Sprite를 재사용하며, 마우스로 조작하는 Slider가 아닌 SPACE 입력을 보여주는 표시 전용 게이지다.

- 예약 입력이 가능한 일시정지 중에만 보인다. 일반 재생·관리 설정·입력 잠금·엔딩에서는 숨긴다.
- 실제 게임의 `Charge01`을 그대로 표시한다. 별도 충전 시간이나 점프 힘을 계산하지 않는다. 최대 세기를 넘겨 누르면 100%를 유지하고, 키를 놓으면 예약을 확정한 뒤 0%로 돌아간다.
- 투명 여백을 제외한 실제 캐릭터 도트 영역을 프레임별로 한 번 읽어 캐싱한다. 캐릭터 반전·확대·회전과 카메라를 반영해 머리 위를 따라간다. 읽을 수 없는/패킹된 텍스처는 Renderer 영역으로 대체한다.
- 실제 화면에서 약 **27×4픽셀**로 확인했다. 화면 배율과 캐릭터 크기에 비례하며 너무 작은 화면에서는 최소 16×4픽셀을 유지한다. 휠 둘러보기로 캐릭터가 화면 밖에 가면 게이지도 숨긴다.
- Inspector의 **캐릭터 대비 게이지 크기**에서 가로 비율·두께·머리 위 간격을 바꿀 수 있다. 게이지와 채움은 Raycast를 받지 않으므로 기존 입력과 UI 클릭을 가로채지 않는다.

## 검증

Unity 6000.3.22f1 실제 Editor Play에서 기존 `PauseGame.TickGame`과 `JumpInputRecorder`를 이용한 자동 입력으로 검사했다. 충전 필드나 표시 값을 직접 주입하지 않았다.

1. 일반 상태 숨김 → ESC 기록 상태에서 빈 게이지 표시.
2. 26프레임 입력 후 실제 충전 **0.509804**, 표시 **0.509804** 일치. `Half.json`, `01_HalfCharge.png`.
3. 최대 시간 이상 유지 시 표시 1.0 포화, 실제 예약 세기는 현재 설정의 최대 **0.85초**로 확정. `Full.json`, `Settings.json`, `02_FullCharge.png`.
4. 설정 상태에서 숨김, 해제 후 빈 게이지 복귀. `Settings.json`, `Release.json`, `03_Released.png`.
5. ESC 재생 시 숨김, 재생 중 다시 ESC로 정지해 입력이 잠긴 상태에서도 숨김. `Playback.json`, `Locked.json`, `04_PlaybackHidden.png`.
6. 검사 중 카메라를 화면 밖으로 옮긴 위치 fixture에서 숨김과 카메라 원위치 복귀 시 추적 재개 확인. 실제 마우스 휠 이벤트를 재생했다는 뜻은 아니다. `Offscreen.json`, `Tracking.json`.
7. `Alignment.json`: 투명 여백을 제외한 머리의 화면 Y 약154.4, 게이지 중심 Y 약159.0. 바 밑면과 머리 사이 간격 약2.5픽셀. 카메라 화면좌표는 아래에서 위 방향이다.

마지막에 Play를 종료하고 검증용 리로드 잠금을 해제했다. 컴파일·Console 오류와 저장 씬의 연결을 확인한다. 이번 표시 전용 변경에서는 99회 전체 코스나 새 실행 파일/Android 실기기 검사를 반복하지 않았다.
