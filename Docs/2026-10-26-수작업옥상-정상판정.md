# 수작업 옥상의 정상 도달 판정

- 정상 조건을 `Goal 재질 + 마지막 4연속 점프`에서 **가장 높은 발판의 실제 착지**로 변경했다.
- 일반 발판, 팔레트로 칠한 발판 모두 대상이다. 현재 09번 씬에서는 사용자가 만든 174.8m 일반 옥상 12구간이 해당한다.
- 최상단 기준은 실제 씬에서 읽은 모든 발판 중 가장 높은 표면 높이다. 같은 높이의 여러 옥상 조각을 모두 인정한다.
- `Pause Game → 정상 엔딩 동작 → Summit Height Tolerance`에서 같은 옥상으로 인정할 높이 오차를 조절한다. 기본값은 0.05m다.
- 높이만 공중에서 통과하거나 더 낮은 발판에 서 있는 경우는 인정하지 않는다.
- 옥상에 선 뒤 **ESC → Space**를 누르면 기존 고정 문구 어퍼컷 엔딩으로 이어진다. 연속 점프 횟수나 발판 번호는 조건이 아니다.
- 수작업 옥상의 Tilemap, 도트, 발판 위치와 폭은 수정하지 않았다.

검증: 실제 09번 씬의 일반 옥상 12구간에 각각 낙하·착지, 공중 및 100번 낮은 발판 거절, 4연속 점프 없이 ESC→Space로 문구 파괴·착지·크레딧까지 Unity Play에서 확인했다. 기록은 `Docs/Validation/ManualRooftop20261026/Runtime.txt`다.
