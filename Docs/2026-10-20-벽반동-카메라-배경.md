# 2026-10-20 벽 반동·낙하 카메라·하늘 배경 수정

프로젝트: `C:\Users\MBC\Documents\GitHub\GamePaused`  
저장 씬: `Assets/Scenes/MainScene.unity`

이 문서는 첫 배경 수정의 기록입니다. 이후 카메라·낙하·회복 동작은 [플레이 피드백 반영 안내](2026-10-20-플레이-피드백.md)의 규칙이 최신입니다.

## 바뀐 동작

- 좌우 벽의 상승·하강 반동 모두 닿는 순간 이동할 방향을 바라봅니다. 원화 후반에 방향이 바뀌는 프레임도 보정하여 다시 벽 쪽을 보지 않습니다.
- 정점에서 기본 3.5m 이상 떨어지면 예약 묶음 중에도 카메라가 하강을 따라갑니다. 연속 배 반동의 다음 하강도 이어서 추적하고, 반동 상승은 새 화면 위치에서 고정합니다. ESC 정지 중에는 화면도 정지합니다.
- 배경은 초록 들판 한 장과 동일한 구름 그림을 맵 아래부터 정상 위까지 아홉 장의 실제 오브젝트로 쌓습니다. 카메라에 따라붙거나 크기·투명도를 바꾸지 않습니다. 플레이 전에도 Scene에서 전체 배치를 볼 수 있습니다.
- 석양 전용 그림은 사용하지 않습니다. 같은 구름과 하늘의 색을 월드 높이 70~175m에 걸쳐 부드럽게 바꿉니다. 각 픽셀의 실제 월드 높이를 사용하여 배경 조각 경계에서도 그라데이션이 이어집니다. 들판은 최하층에 고정됩니다.
- 사용자가 비활성화한 사다리 세 개와 바람의 수동 위치를 포함하여 발판·벽·장치의 설정 및 Transform을 보존했습니다. 이전 성 배경은 비활성 백업으로 남깁니다.

## Inspector 설정

1. 게임 관리자 > `PauseBatchCamera` > **두 발판 이상 낙하 추적**에서 기준 거리와 추적 속도를 조절합니다.
2. `03 배경 · 초록 들판과 구름과 석양` > `PauseSkyBackdrop`에서 낮·석양 하늘색, 구름의 석양 색, 석양 전환 높이(70~175m)를 조절합니다. 자식 배경 조각의 Transform도 직접 편집할 수 있습니다.
3. 추가 연결이나 메뉴 실행 없이 저장된 MainScene을 재생하면 적용됩니다.

## 현재 검증과 범위

- `Docs/Validation/WorldSky20261020/Validation.json`: 전체 높이의 고정 배치, 카메라 이동에도 Transform 불변, 같은 구름 원본, 모든 조각 경계의 실제 픽셀 색 연속, 실제 석양 색 변화, 정지 흑백과 재개 후 복원, 셰이더 오류 없음 검사.
- 같은 폴더의 `Regression.json`: 실제 PNG를 사용하는 캐릭터 표시 컴포넌트의 좌우·상승·하강 48프레임 선택, 독립 물리의 120m 낙하와 실제 카메라 컴포넌트의 추적·상승 고정·ESC 정지 검사.
- `ExpansionValidation.json`: 현재 씬 연결과 고정 시간 물리 검사. `ExpansionRuntimeValidation.json`: 실제 Unity Play에서 시작점 두 예약 도약, 묶음 카메라, 배 반동·회복·포탈·로프·트램펄린·바람의 정지 표시와 새 배경의 스프라이트·투명도·Transform 불변 검사. 씬에서 꺼둔 사다리의 실행 표시는 건너뛰며 독립 물리 검사로 확인합니다.
- `SavedGeometryPreservation.json`: 이번 수정 직전 저장 씬과 발판·벽·장치의 직렬화 데이터·활성 상태·Transform이 동일한지 비교한 결과입니다.
- `Build/WorldSkyEvidence/meadow.png`, `clouds.png`, `gradient.png`, `sunset.png`: 임시 카메라로 실제 씬을 각 높이에서 렌더한 미리보기입니다. 실제 코스 완주 화면은 아닙니다.
- `Docs/Validation/SkyRevision20261020`은 카메라에 따라붙던 첫 배경 버전의 이전 검증 기록입니다.
- 전체 175m 코스 완주와 Android 실기기 실행은 이번 검증에 포함하지 않았습니다. 기존 Windows/APK 빌드는 이번 수정을 포함하지 않으며, 다시 빌드해야 반영됩니다.

## 생성 이미지

내장 imagegen으로 생성한 원본 PNG를 `Assets/Art/DesktopSky`에 보관합니다. 현재는 `meadow.png`와 `clouds.png`만 사용하며 `sunset.png`는 사용하지 않는 원본으로 남깁니다. Point 필터·압축 없음으로 가져옵니다. 전체 생성 프롬프트는 [sky-prompts.json](2026-10-20-sky-prompts.json)에 기록했습니다. 현재 색 변화는 `Assets/Shaders/PauseWorldSky.shader`와 저장된 두 재질이 처리합니다.
