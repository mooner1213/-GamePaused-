# 0.3.0 변경과 편집 안내

## Unity에서 여는 위치

- Unity 버전: 6000.3.22f1
- 시작 씬: Assets/Scenes/MainScene.unity
- 게임 관리자: 일시정지 게임 · 설정은 Inspector에서
- 발판·벽·장치는 Hierarchy의 확장 코스 그룹 아래에 실제 오브젝트로 저장되어 있습니다. 재생하지 않고 Transform 및 전용 컴포넌트를 수정할 수 있습니다.
- 예전 35m 코스는 백업 그룹으로 보관하며 새 코스 물리에 포함하지 않습니다. ID가 겹치지 않도록 새 오브젝트에 고유 번호를 지정합니다.

## 조절하는 곳

- PauseGame > 점프와 반사 물리: 점프 세기, 중력, 얼음, 배 반동, 로프·사다리 접촉, 포탈 재진입, 붕괴 시간을 조절합니다.
- PauseCharacterView: 실제 상태별 모션과 재생 속도를 조절합니다. 벽 반동은 닿는 순간 반대 방향을 보며 후반 프레임에서도 그 방향을 유지합니다. 기본 캐릭터는 안경 없는 수염·흰 상의·긴바지의 사람입니다.
- PauseBatchCamera: 예약 묶음 종료 후 카메라가 돌아오는 시간과 여유 높이, 큰 낙하의 추적 기준(기본 3.5m)과 속도를 조절합니다.
- PauseSkyBackdrop: Hierarchy의 `03 배경 · 초록 들판과 구름과 석양`에서 같은 구름에 입힐 낮·석양 색과 전환 높이(70~175m)를 조절합니다. 그 아래 들판·구름 조각은 맵 전체 높이에 고정되어 있으며 Transform을 직접 편집할 수 있습니다. 카메라에는 따라붙지 않습니다.
- PauseHud: 패널 배치, 글자 크기, 색상, 궤도 점과 엔딩 연출 표시를 조절합니다.
- PauseTouchInput: 휴대폰·태블릿의 점프와 정지 버튼 영역을 조절합니다. HUD도 같은 영역을 표시합니다.
- PausePlatformObject / PauseWallObject: 발판 종류·이동·반사 범위를 조절합니다.
- PauseGimmickObject: 포탈 짝 번호·출구, 로프 길이·진폭, 사다리 목적 발판, 트램펄린 비율, 바람 가속도를 조절합니다.
- 새 Tag/Layer를 수동으로 추가할 필요는 없습니다. 배경·장식·구조물은 SpriteRenderer 표시 순서로 쌓습니다.

## 동작

Space를 누른 시간과 횟수로 예약하고 ESC로 정지·재생합니다. 예약 점프가 남았을 때 추가 입력은 잠깁니다. 큰 낙하가 시작되면 남은 점프를 취소하고 반동 상승·하강·기립까지 카메라가 계속 따라갑니다. 기립 완료 후 위쪽 발판 방향을 자동 선택하고 새 점프를 입력합니다. ESC 정지 중에는 자동 카메라도 멈추며, 휠로만 위아래 둘러볼 수 있습니다. 휠 클릭 또는 ESC로 자동 카메라 위치로 돌아갑니다.

높은 낙하는 여러 차례 배 반동과 앞구르기로 이어지고, 마지막에는 엎드린 뒤 일어납니다. 벽 반동은 상승·하강 모션을 구분합니다. 엔딩은 어퍼컷 후 내려와 착지까지 재생합니다.

포탈, 매달린 위치에 따라 길이가 달라지는 무감쇠 로프, 자동 등반 사다리, 낙하 높이 2/3를 되튀는 트램펄린, 방향성 바람을 추가했습니다. 바람은 얼음에서 더 밀어냅니다.

## 코딩 규칙

Docs/unity_codex_coding_rules.md와 루트 AGENTS.md를 따릅니다. 입력 기록, 게임 상태, 고정 물리, 예측, 캐릭터 모션, 카메라, 소리, HUD 화면을 별도로 구성했습니다. 직렬화 필드 이름 변경은 FormerlySerializedAs로 이전 저장값을 이어받습니다.

## 검증 자료 읽는 법

- Build/ExpansionValidation.json: 실제 저장 씬의 연결과 독립 물리 실험입니다.
- Build/ExpansionRuntimeValidation.json: 실제 게임 입력으로 시작점 두 도약을 재생하며 카메라 잠금과 장치별 정지 표시를 검사합니다. 장치 상태 준비에 Reset을 쓰므로 175m 전체 코스 완주 증거는 아닙니다.
- Build/ExpansionEvidence: 하층·중층·상층 화면입니다.
- Windows 실행 및 APK 빌드 성공은 Android 실기기 설치·성능 확인과 다릅니다. 실제 기기 증거가 없으면 실기기 테스트 완료로 표기하지 않습니다.
