# -GamePaused-
일시정지 기능을 이용한 도트형 2D 등반 플랫포머 게임

## 최신 디자인 · 2026-10-21

메인은 **09 RGB 키보드**입니다. Unity 메뉴 **일시정지 게임 → 팔레트 → 09 RGB 메인 편집 열기**에서 바로 편집할 수 있습니다. 메인과 비교 씬 15개에 테마 벽·발판, 성 내부 벽과 별도 창문, 거리별 네 배경 레이어를 적용했습니다. 실제 팔레트 16개를 **한 칸 분할 타일 1,579개**로 바꿨습니다. 일반·금간은 4×1, 기름·타이머는 4×2, 옆 성벽은 1×4 묶음이며 뒤 성벽은 1×1칸·1.01배로 채웁니다.

캐릭터가 가로 중앙을 통과하면 카메라가 따라가고 성 양끝에서 멈춥니다. 점선·착지 번호는 **3프레임 간격 사람 잔상**으로 바꿨습니다. 발판 그림을 0.2m 올려 윗면 안쪽에 서 보이게 했고 실제 106개 발판의 배치는 보존했습니다. 내부 방향 전환 벽과 중간 스킵 포탈은 제거했으며 **정상의 마지막 출구는 유지**합니다. [편집 방법과 최신 검증 범위](Art/GridRevision20261021/README.md)를 확인하세요. 아래 0.3.0 설명은 이전 버전 기록입니다.

## 열기

Unity **6000.3.22f1**에서 이 저장소 폴더를 프로젝트로 열고 **Assets/Scenes/MainScene.unity**를 엽니다.
발판·벽·로프·마지막 출구는 실제 씬 오브젝트이며, 성 내부 벽·창문·추가 발판은 Tile Palette에서도 편집할 수 있습니다.

## 조작

- ESC 또는 정지 버튼: 시간 정지 / 예약 재생 전환
- Space 또는 점프 버튼: 누른 시간만큼 점프 세기를 기록하고, 놓을 때 점프 한 번 예약
- 방향키 없이 벽 충돌로 방향 전환, 큰 낙하 후 회복하면 위쪽 발판 방향 자동 선택
- 예약된 점프가 남아 있으면 정지해도 추가 입력은 잠김
- 큰 낙하(기본 3.5m)가 시작되면 남은 점프 취소, 카메라는 반동 상승·하강·회복이 끝날 때까지 계속 추적
- 마우스 휠: 위아래 둘러보기 / 휠 클릭 또는 ESC: 자동 카메라 위치로 복귀

## 0.3.0 구현

사람 캐릭터의 점프, 상승·하강 벽 반동, 여러 차례 배 반동과 앞구르기, 마지막 엎드림과 일어나기, 어퍼컷 후 착지 모션을 연결했습니다.

폭 24m·높이 175m 코스에 발판 106개·반사 벽 18개·기믹 14개를 배치했습니다. 배경은 초록 들판 한 장과 같은 구름 그림을 월드 전체 높이에 고정 배치합니다. 상층은 그림을 교체하지 않고 월드 높이에 따라 하늘과 구름을 서서히 석양 색으로 바꿉니다. 이전 성 배경은 비활성 백업으로 보관합니다.

포탈, 잡는 위치에 따라 길이가 달라지는 무감쇠 로프, 자동 등반 사다리, 낙하 높이의 2/3를 되튀는 트램펄린, 바람과 얼음의 추가 밀침을 포함합니다. 높은 낙하 기준 기본값은 발판 두 칸 정도인 3.5m이며 Inspector에서 조절합니다.

## 빌드와 검증

Unity 메뉴 **일시정지 게임 → 확장판 빌드**에서 Windows 또는 Android APK를 생성합니다. MainScene 저장과 기믹 검사가 먼저 실행됩니다.

생성 파일은 `Build/Expansion`에 저장하며 Git에는 포함하지 않습니다. Android는 API 26 이상, ARM64/ARMv7, 가로 화면 휴대폰·태블릿용 단일 APK입니다.

`-expansionQA` 실행 인수는 실제 시작점 두 도약과 장치별 정지 표시를 자동 검사합니다. 이 검사는 장치 상태 준비에 Reset을 사용하며 **175m 전체 코스 완주 증거는 아닙니다.** Android 빌드 성공도 실제 기기 설치·성능 검증과 구분합니다.

검증 기록은 [Docs/Validation](Validation)에 보관합니다. 폰트 라이선스는 Assets/StreamingAssets/NotoSansCJK-OFL.txt를 확인합니다.
