# 기존 발판과 옆 성벽의 Tilemap 편집

메인 `Assets/Scenes/MainScene.unity`의 기존 발판 106개와 옆 성벽 2개에 실제 타일이 채워진 편집 Grid를 저장했습니다. 기존 성 배경·창문·새 발판 추가 Tilemap도 유지합니다.

## 기존 발판 그림 수정

1. Hierarchy에서 수정할 `발판 001…` 같은 발판 오브젝트를 선택합니다.
2. Inspector의 **이 발판의 Tilemap 칠하기** 버튼을 누릅니다.
3. Tile Palette에서 조각을 선택해 Scene에 칠하거나 지우개로 지웁니다. Ctrl+S로 씬을 저장합니다.

각 발판 아래 **타일 디자인 Grid · 직접 칠하기 → 01 발판 디자인 · 칠하기와 지우기**가 있습니다. 기울기와 현재 발판 폭에 맞춘 로컬 격자이므로, 팔레트 4칸 묶음이 기존 그림 한 조각의 너비에 해당합니다. 이동 발판의 그림도 부모와 함께 움직이며 타이머·금간 발판의 소멸·복구를 따릅니다. 숫자와 마지막 출구는 별도로 보존했습니다.

## 옆 성벽 그림 수정

성 외벽 오브젝트를 선택하고 Inspector의 **이 성벽의 Tilemap 칠하기**를 누릅니다. 자식 Grid에서 레이어를 바꿀 수도 있습니다.

- **01 옆 성벽 몸통**: 반복 벽의 본체.
- **02 옆 성벽 이음띠**: 부품 사이 연결 장식. 필요 없으면 해당 Tilemap을 지우거나 끕니다.
- **03 옆 성벽 상하 마감**: 꼭대기와 바닥 장식.

우측 벽의 기존 좌우 반전과 각 레이어의 그리기 순서를 유지했습니다. 얇은 배경 심재는 남아 있으므로 몸통 도트를 지우면 그 뒤 바탕이 보입니다.

## 디자인과 판정의 구분

기존 발판·옆 성벽의 새 Tilemap은 **그림 편집용**입니다. 도트를 지워도 실제 표면이나 벽 판정은 사라지지 않습니다. 기존 발판의 위치·너비·기울기는 `발판 표면`, 성벽의 범위는 `벽 반사면` 연결 오브젝트를 조절합니다.

새로운 실제 발판을 추가하려면 공통 편집 Grid의 **03 발판 추가 · 실제 착지 판정**에 발판 타일을 칠합니다. 이 레이어는 재생 시 공통 물리·예측에 읽힙니다. 원래 위치의 발판을 두고 이 레이어에도 겹쳐 칠하면 두 판정이 생길 수 있으므로 기존 발판의 그림 수정에는 해당 발판의 로컬 Tilemap을 사용하세요.

사용자가 만든 도트도 Unity Sprite/Tile로 만들어 Tile Palette에 넣고 같은 방식으로 칠할 수 있습니다. 현재 팔레트 조각 규격은 32×32픽셀·PPU32입니다. 기존 발판 디자인 Tilemap에서는 일반 Unity Tile도 그림으로 표시할 수 있습니다. 공통 '발판 추가'의 실제 판정은 게임용 `PauseDesignTile` 자산을 사용합니다.

이번 변환은 메인 씬에 적용했습니다. 다른 비교 씬에서도 **일시정지 게임 → 팔레트 → 현재 코스의 발판과 옆 성벽을 Tilemap으로 편집** 메뉴를 사용할 수 있습니다. 이미 Grid가 있는 오브젝트는 다시 만들지 않아 칠해 둔 디자인을 보존합니다.

검증 자료는 `Docs/Validation/CourseTilemaps20261022`에 있습니다. 편집기 렌더 이미지와 실제 재생 검증을 구분해서 기록합니다. Android 실기기나 전체 코스 완주는 이번 수정의 검증 범위가 아닙니다.
