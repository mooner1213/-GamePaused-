# 2칸·6칸 발판과 정상 어퍼컷

> 이후 옥상·문구 연출이 추가되었으며 현재 엔딩 입력은 ESC → Space다. 최신 동작은 [옥상과 고정 문구 엔딩](2026-10-26-옥상과-고정문구-엔딩.md)을 따른다. 아래 엔딩 실행 기록은 그 이전 버전의 검증 결과다.

## 팔레트

- 15종 테마 팔레트와 `00 전체 벽 디자인 · 15종`의 맨 아래에 길이별 발판을 추가했다.
- 각 테마에 일반·기름·금간·타이머 × 짧은 2칸·긴 6칸 = 8묶음이다.
- 기존 4칸 발판의 양끝 32픽셀은 보존하고 가운데를 제거하거나 반복했다. 일반·금간은 높이 1칸, 기름·타이머는 높이 2칸이다.
- 브러시로 묶음 전체를 선택해 `03 발판 추가 · 실제 착지 판정` Tilemap에 칠하면 한 발판으로 연결된다. 발이 서는 위치는 기존과 동일하게 윗면보다 0.2m 안쪽이다.
- 제작 메뉴: `일시정지 게임/팔레트/2칸·6칸 발판 추가`. 기존 팔레트 위치와 씬은 보존한다. 전체 팔레트를 다시 준비해도 길이별 발판을 포함한다.

## 엔딩

- 기존 정상 도달 조건을 완료한 뒤 Space/점프 버튼을 한 번 누르면 일반 점프 대신 어퍼컷을 재생한다. ESC 정지 중에도 같은 입력으로 실행된다.
- 배경과 실제 물리는 정지한 채 캐릭터의 어퍼컷·하강·착지만 진행한다. 엔딩 재생 중 ESC는 연출을 중단하지 않는다.
- `Pause Game → 정상 엔딩 동작 → Ending Sequence`에서 슬로우 속도와 캐릭터 최대 배율을 조절한다.
- 기본값: 시간 배율 0.35, 최대 배율 1.15. 1.3초 원화 동작을 약 3.7초에 걸쳐 재생하며 착지와 재시작 시 원래 크기로 돌아온다.

## 검증 범위

- 15개 테마, 120묶음, 720개 분할 타일 생성.
- 모든 묶음을 실제 Tilemap에 칠해 단일 표면·폭 2m/6m·원래 재질·실제 착지·예측 일치를 검사했다.
- Unity Play의 정상 상태를 구성해 정지 전/후 입력을 각각 검사했다. 두 경우 모두 어퍼컷 12프레임·적중·착지·크레딧·물리 정지·배율 복구를 확인했다.
- 전체 코스 완주나 Android 실기기 검사는 이번 검증에 포함하지 않았다.
- 세부 기록: `Docs/Validation/PlatformEnding20261026/`.
