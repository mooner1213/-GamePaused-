# 옥상 실제 Tilemap · 가로 연결 개정

이전 버전의 빈 Tilemap + 자식 SpriteRenderer 구조를 실제 타일이 칠해진 앞·뒤 Tilemap으로 전환한다.

- `01 옥상 뒤 성벽 · 원화 첫 줄`: 정렬 순서 -15. 캐릭터 뒤의 성벽.
- `03 옥상 앞 난간 · 원화 셋째 줄 · 캐릭터 가림`: 정렬 순서 30. 캐릭터 앞을 가리는 난간.
- 기존 소품과 나머지 맵·발판·기믹·성 내부 타일은 보존한다.

원화에서 빈 투명 테두리를 먼저 자른다. 벽은 가로를 정수 칸으로 조금 늘리고 바닥줄의 투명 틈을 같은 원화색으로 채운다. 실제 보이는 세로 높이는 원본을 기준으로 유지한다. 의도된 성벽 톱니와 기둥 위쪽 실루엣은 남긴다. 팔레트에는 완전히 투명한 조각을 넣지 않는다.

검은 원본 배경과 함께 투명해졌던 벽 몸통 내부의 모르타르도 해당 테마의 어두운 원화색으로 채운다. 벽돌 줄눈 사이로 하늘이 비치는 현상을 막는다.

분할 조각은 모두 32×32픽셀, PPU32, 단위 변환행렬로 한 칸에 대응한다. 마지막 열에 남던 빈 폭이 생기지 않는다. 씬도 팔레트와 동일한 타일을 사용한다.

양쪽 외벽 안쪽이 X -12~12인 현재 씬들은 옥상 장식을 X -13~13으로 확장한다. 옥상 발판의 실제 너비나 충돌 판정은 바꾸지 않는다.

옥상의 마지막 출구 포탈은 15개 테마 씬과 MainScene에서 모두 제거했다. 정상 착지 → ESC·점프 → 문구 파괴 → 하늘 상승 엔딩을 그대로 사용한다. 디자인 생성 도구에서도 출구를 다시 만들지 않는다.

## 편집

Unity 상단 `일시정지 게임 → 옥상 디자인 → 뒤 성벽 타일맵 편집` 또는 `앞 난간 타일맵 편집`을 누르면 대상 Tilemap과 팔레트를 함께 연다. 09번에는 `17 RGB 옥상 뒤 성벽`, `18 RGB 옥상 앞 난간` 전용 팔레트가 있다. 브러시로 칠하고 지우개로 지운 결과가 실제 그림에 반영된다.

15개 기존 테마 팔레트와 전체 모음·옥상 모음에도 새 조각을 등록한다. 옥상 이외의 기존 팔레트 셀은 이동시키거나 지우지 않는다.

자산: `Assets/Art/RooftopGrid20261028`, 타일: `Assets/Tiles/RooftopGrid20261028`.

검증 자료: `Docs/Validation/RooftopGrid20261028`.

## 적용·검증 결과

- 15개 테마 씬과 MainScene 저장 완료. 앞·뒤 몸통 바닥 52칸이 X -13~13 범위에 연속으로 있고 빈칸 0. 옛 연결 부품 SpriteRenderer 26개씩을 실제 Tilemap 타일로 대체했다.
- 15테마 벽의 가로 바닥줄 투명 픽셀 0. 모든 새 조각은 32픽셀/PPU32와 단위 변환행렬을 사용한다. 갤러리의 시트도 실제 팔레트 타일로 합성했다.
- 09번 편집 상태에서 뒤 성벽 한 칸 삭제·복원, 빈 칸에 새 타일 칠하기, 앞·뒤 데이터 독립성을 확인했다. 검사에 쓴 변경은 복원했다. 두 레이어에는 Collider가 없다.
- 09번 Editor Play 4장 렌더 비교에서 캐릭터 1,211픽셀이 앞 난간으로 가려지고 1,960픽셀은 보였다. 실제 TilemapRenderer로 가림을 확인했다.
- 정지 시 Tilemap의 흑백 값 1, 재생 후 0 확인. ESC·점프 → 문구 파괴 → 어퍼컷 03번 → 크레딧·Y 513까지 상승도 확인했다.
- 16개 씬의 저장 전후 비교에서 바뀐 기존 항목은 앞·뒤 레이어 Transform 2개와 Tilemap 2개, 대체한 스프라이트 Transform 26개뿐이다. Collider 변경 0. 발판·기믹 설정 및 다른 Tilemap의 타일·색·행렬을 보존했다.
- 옥상 이외의 기존 팔레트 셀 변경 0. 16개 씬의 새 렌더링과 비교 갤러리를 갱신했다.
- 컴파일 오류 0. 가져오기 코드 `PauseStageSpriteImporter.cs`의 기존 CS0618 경고는 이번 범위에서 수정하지 않았다. 위의 실행 검사는 Editor의 자동 입력이며 새 Windows/APK 빌드 검증은 아니다.

현재 구현: `Assets/Editor/PauseRooftopTilemapRevision.cs`. 이전 원화 생성/배치 메뉴는 새 격자 자산이 있으면 이 개정 도구로 연결된다. 이미 칠한 옥상 레이어를 전환 메뉴로 다시 덮어쓰는 일은 차단한다. 평소 수정은 앞·뒤 편집 메뉴와 브러시·지우개를 사용한다.
