# 키보드 성벽 재질·구조 시안 6종

2026-10-20. 사용자가 제공한 여덟 가지 팀원 시안을 참고하여 내장 imagegen으로 각 콘셉트를 별도 생성했다. 기존 A/B/C 시안은 보존하고 새 폴더에 저장했다.

## 비교와 파일

`비교갤러리.html`을 브라우저로 열면 6종을 나란히 비교할 수 있다. 하늘색·어두운색·밝은색 배경을 전환하고 이미지를 눌러 원본을 볼 수 있다. 갤러리의 상대 경로가 유지되도록 프로젝트 안에서 연다.

이미지 위치: `Assets/Art/KeyboardCastleConcepts/20261020-v2/`

각 PNG는 1448×1086 RGBA다. 원본 알파와 픽셀을 보존했다. 성벽 이미지에 흙·잔디·하늘을 추가하지 않았다. `prompts.json`에는 공통 조건과 각 콘셉트의 전체 프롬프트, `source-files.json`에는 생성 원본과 저장 경로를 기록했다.

## 부품 구성

각 시트는 4열 × 2행, 총 8부품이다.

- 윗줄: 왼쪽 상단 / 왼쪽 중간 / 왼쪽 하단 / 왼쪽 파손 구간.
- 아랫줄: 오른쪽 상단 / 오른쪽 중간 / 오른쪽 하단 / 오른쪽 파손 구간.
- 왼쪽 발판은 오른쪽으로, 오른쪽 발판은 왼쪽으로 돌출된다.

Unity Project 창에서 각 PNG를 펼치면 `V2_01_L_Top` 같은 이름으로 개별 스프라이트를 선택할 수 있다. `01`~`06`은 콘셉트 번호, `L/R`은 좌우, `Top/Middle/Bottom/Opening`은 상단/중간/하단/파손이다. 총 48개 스프라이트다.

Point 필터, 무압축, 밉맵 없음, PPU 약 120.67로 설정했다. 프레임의 바깥쪽 축과 아래쪽을 기준으로 피벗을 잡았다. 이 설정은 기존 사람 캐릭터의 PPU 32와 함께 비교할 출발값이며 최종 코스 크기에 맞춰 조정할 수 있다. `sprite-layout.json`에 실제 분할 좌표와 피벗을 기록했다.

## 확인과 적용 범위

6장의 투명 알파, 이미지 크기, 시안별 8개 Unity 스프라이트 가져오기를 확인했다. 기존 MainScene의 저장 상태는 변경하지 않았다.

이번 결과는 재질과 구조를 비교하기 위한 디자인 시안이다. 중간 부품의 장식 캡과 각 모듈의 외곽선·배선 등은 AI 생성 결과에 따라 경계가 완전히 맞지 않을 수 있다. 픽셀 단위의 무한 반복 타일이나 통행 가능한 충돌체가 완성되었다는 의미는 아니다. 최종 콘셉트 채택 후 연결부 정리와 충돌체 설정을 진행한다.
