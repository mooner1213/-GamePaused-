# 최대 불규칙 발판 배치 시안 · 씬 미반영

현재 09번 RGB 테마의 실제 2·4·6칸 발판 도트를 사용해, 106개 발판의 X·Y·길이·종류를 독립적인 확률 좌표로 섞은 사진이다. 세로 일정 간격이나 좌우 교대 규칙은 사용하지 않았다. 발판 그림끼리 직접 겹치는 경우만 후보를 다시 뽑았다. 동일 시안을 재생성할 수 있도록 seed 20261029를 사용했다.

- 일반 67개 / 기름 16개 / 금간 14개 / 타이머 9개
- `최대랜덤_하중상_미리보기.png`: 왼쪽 하층, 가운데 중층, 오른쪽 상층. 각 구간을 동일한 배율로 보여 주며 일부 높이는 겹쳐 보인다.
- `최대랜덤_전체타워.png`: 전체 높이를 한 장으로 보는 원본 1280×8192 PNG
- `배치좌표_시안전용.csv`: 위 사진에만 쓰인 좌표와 길이·종류
- `GeneratePreview.cs.txt`: 저장된 씬을 바꾸지 않고 숨김 그림 오브젝트와 전용 카메라로 사진만 만드는 재현 코드

이번 요청은 배치 제안 사진이므로 실제 씬 발판·기믹·물리를 수정하지 않았다. 사진 생성 전후 16개 씬 파일의 SHA256이 모두 같았고, 현재 씬의 편집 상태도 그대로였다(`시안검사.txt`, `씬해시_사진생성전.json`). 숨김 오브젝트는 렌더 후 모두 해제했다.

시안 사진은 실제 게임 자산을 Unity에서 렌더한 이미지다. 현재 게임에 적용된 맵이나 실제 플레이 녹화가 아니다. **기존 점프력·방향 전환·예약 규칙으로 완주할 수 있는지는 검증하지 않은 최대 불규칙 디자인 시안**이다. 향후 적용 시에는 같은 물리 모델로 도달 가능성과 지나치게 빈 구간을 검사·조정해야 한다.
