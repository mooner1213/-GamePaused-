# image_gen 색상 시안 프롬프트

도구: 내장 image_gen / 편집 모드 / transparent_background=true.

입력: 사용자가 첨부한 `KakaoTalk_20261028_164614790.png`.

```text
Edit target: attached pixel art rooftop castle parts sheet. Precise object edit for Unity 2D game. Remove the entire SECOND and FOURTH horizontal rows (the two long assembled castle ramparts). Keep ALL FIVE separate pieces of the FIRST row, ALL FIVE separate pieces of the THIRD row, and ALL the flags and rubble pieces of the FIFTH bottom row. Keep every remaining piece at exactly the original position, original shape, original size, silhouette, proportions, cracks, outline, pixel cluster details and spacing. Do not redesign, stretch, rescale, merge, or add anything. Change ONLY the palette of remaining pieces to match a dark RGB mechanical keyboard castle: dark charcoal / blue-gray keycap stone, subdued violet-gray edge highlights, cyan and hot magenta RGB emissive strips and crests instead of orange lava. Make the first row's five pieces read a little darker as a rear wall; third row five pieces slightly brighter as front parapet. The flags and rubble keep identical silhouettes but use matching dark navy / magenta / cyan textile and rubble colors. Genuine transparent background, no black background, no checkerboard, no text or labels. Preserve original coarse visible square pixel art, no painterly smoothing or extra detail. This is a color-only production sprite reference, geometric invariants are essential.
```

출력 사본: `RGB색상시안.png`. 미세한 형상 변화를 게임에 옮기지 않기 위해 색상 참고로만 사용했다. 최종 자산은 원본 좌표에서 명암과 테마 색상표만 치환하여 만들었다. 구현과 테마별 색상표는 `Assets/Editor/PauseRooftopThemeArt.cs`에 있다.
