# 15테마 × 다섯 겹 건축물 배경

15개 비교 씬의 건축물 배경을 각각 다른 그림으로 교체했습니다. 메인 씬에도 09 RGB 키보드의 다섯 겹을 적용했습니다. 테마마다 한 장의 투명 원본에 서로 다른 건축물 다섯 줄을 제작하고, 실제 행 경계로 Sprite를 나눴습니다. 동일 그림의 색상 변경으로 대체한 레이어는 없습니다.

- [15테마 건축물 원본 한눈에 보기](ArtOverview.png)
- [15테마 씬 한눈에 보기](ScenesOverview.png)
- [생성 프롬프트·원본 출처·Sprite 분할 범위](AtlasCatalog.json)

제작은 기본 `image_gen` 도구를 사용했습니다. 원본 RGBA PNG의 알파를 보존하고, 프로젝트의 `Assets/Art/FiveDepth20261022/각 테마/FiveDepth.png`로 복사했습니다. 같은 폴더의 `Depth01.asset`부터 `Depth05.asset`가 실제 씬에 연결된 Sprite입니다. 다른 컴퓨터에서도 프로젝트 안의 PNG와 Sprite를 그대로 사용합니다.

## 다섯 거리의 구성

Hierarchy의 **05 입체 배경 · 하늘과 구름 + 건축물 5겹** 아래에서 선택합니다. 하늘과 구름은 별도로 유지하므로 전체 거리 레이어는 7개입니다.

| 레이어 | 세로 시차 비율 | 기본 불투명도 | 출발 카메라보다 올라간 높이에 따른 사라짐 |
|---|---:|---:|---|
| 03 초원경 · 먼 랜드마크 | +0.94 | 0.62 | 140~205m 사이에 서서히 옅어짐 |
| 04 원경 · 성탑과 연결교 | +0.90 | 0.73 | 95~140m |
| 05 중경 · 지붕과 회랑 | +0.78 | 0.84 | 60~95m |
| 06 근경 · 외곽 건축물 | +0.55 | 0.94 | 30~60m |
| 07 최근경 · 낮은 구조물 | −0.04 | 1.00 | 12~30m |

수치는 카메라 이동에 대한 월드 좌표 이동 비율입니다. 먼 건물은 카메라를 거의 따라와 화면에서 천천히 아래로 지나갑니다. 최근경은 상승하는 카메라의 반대 방향으로 조금 움직여 더 빨리 아래로 멀어집니다. 원본 그림도 멀수록 대비와 세부 묘사가 약하고, 가까울수록 어둡고 또렷합니다.

건축물을 위로 반복해서 쌓지 않았습니다. 출발에는 다섯 그림이 시야에 있고, 올라가면 가까운 건물부터 아래로 남겨집니다. 정상 근처에는 가장 먼 랜드마크의 윗부분만 희미하게 보입니다. 내려오면 반대 순서로 자연스럽게 돌아옵니다. ESC로 시간을 정지하면 시차와 높이별 퇴장 상태도 멈춥니다.

움직임은 기존 카메라 이동에 맞춥니다. 예약 점프 동안 카메라를 고정하는 기존 규칙은 그대로 유지했습니다. `Pause Design World View`의 각 거리에서 시차와 사라짐 높이를 Inspector로 조절할 수 있습니다.

## 편집 보존과 검사 범위

### 097번 발판으로 바로 이동해서 확인

재생 후 Game 창에 포커스를 두고 **Shift + 0**을 누르면 097번 발판(현재 코스 기준 168m)에 캐릭터와 카메라가 함께 이동합니다. 좌우 Shift와 상단 숫자 0·숫자패드 0을 지원합니다. 기존 예약 점프·낙하·회복·엔딩 상태를 정리하고 해당 발판에 서게 하므로 바로 배경을 둘러보거나 ESC로 정지할 수 있습니다.

Hierarchy의 **일시정지 게임 · 설정은 Inspector에서** 오브젝트 → **Pause Game → 배경 확인용 이동 치트 → Shift + 0 이동 치트 사용**에서 켜고 끕니다. **이동할 발판 번호**의 기본값은 97입니다. 실행 중에도 변경할 수 있으며, 영구 저장하려면 재생을 끈 상태에서 변경하고 씬을 저장합니다. 이 기능은 사용자 배경 Y 위치나 코스 배치를 다시 만들지 않습니다.

성 배경·창문·발판·옆 성벽 Tilemap과 실제 코스 판정, 기믹, 출구를 보존했습니다. 변경 전 백업과 현재 씬의 Tilemap 직렬화 블록을 비교한 결과는 `Docs/Validation/FiveDepth20261022/AssetAndTilemapAudit.json`에 있습니다.

같은 폴더의 `Previews`는 저장된 씬의 높이별 카메라 렌더와 편집기 검사, `Runtime`은 실제 Editor Play에서 씬을 로드한 뒤 카메라 높이를 준비한 검사입니다. 시작·중간·정상, 거리별 이동, 정지, 내려온 뒤의 복원을 확인합니다. 이것은 캐릭터의 175m 전체 완주나 Android 실기기 검증을 뜻하지 않습니다.

메뉴 **일시정지 게임 → 배경 → 15테마 다섯 겹 배경 적용**은 제작 도구입니다. 수작업으로 건축물 배치를 다듬은 뒤에는 일괄 재적용 대신 해당 레이어를 직접 편집하세요. 그림 외의 코스나 Tilemap은 이 도구에서 재생성하지 않습니다.
