같은 코스에서 **벽·발판 재질·기믹 외형·배경**을 비교하기 위한 씬 묶음이다. 2026-10-21에 **09 RGB 키보드**를 메인으로 선정했다. 45개 미리보기도 최신 씬으로 다시 렌더링했다. 팔레트 편집·독립 창문·입체 배경과 최신 검증은 [현재 편집 안내](../RGBMain20261021/README.md)를 확인한다. 아래 검증 수치와 MainScene 해시는 2026-10-20 당시의 기록이다.

[15종 비교 갤러리 열기](비교갤러리.html)

## 빠르게 비교하기

1. `비교갤러리.html`을 브라우저로 연다. 이 문서와 `Previews` 폴더의 상대 위치를 유지한다.
2. **하층 / 중층 / 상층** 버튼을 누르면 15개 카드가 같은 월드 높이로 바뀐다.
3. 이미지를 누르면 원본 PNG를 확대해서 볼 수 있다. 확대 창의 이전·다음 버튼 또는 키보드 좌우 화살표로 디자인을 바꾸고, Escape로 닫는다.
4. 마음에 드는 카드의 **메인 후보**를 체크한 뒤 **후보만 보기**로 좁혀 비교한다. **후보 해제**는 선택 전체를 지운다.

후보 선택은 해당 브라우저의 `localStorage`에만 저장하며 외부로 보내지 않는다. 다른 브라우저·기기에는 자동 공유되지 않는다. 로컬 파일 저장이 제한된 브라우저에서는 이번 탭에서만 선택이 유지된다는 안내가 나온다.

**Unity 편집 씬 미리보기 · 실제 플레이 녹화 아님**

갤러리 이미지는 저장된 Unity 씬을 재생하지 않고 렌더링한 정지 화면이다. 화면의 캐릭터는 크기 비교용 대기 스프라이트이며, 해당 높이까지 플레이해 도달한 장면을 뜻하지 않는다.

### 편집 위치

발판·벽·장치의 **원래 루트 오브젝트는 판정과 위치를 담당**한다. 디자인 비교 씬에서는 원본 판정용 `SpriteRenderer` 표시를 숨기고, 그 아래 **`디자인 스킨 · 물리 원본 보존`** 자식에 테마 그림을 배치한다.

- 외형만 수정하려면 해당 **디자인 스킨 자식**의 SpriteRenderer·색·로컬 위치·로컬 크기를 편집한다.
- 발판 위치·폭이나 기믹 판정을 바꾸려면 원래 루트의 Transform과 연결된 판정 설정을 확인한다. 디자인을 비교하는 동안에는 같은 코스 조건이 유지되도록 이 값을 맞춘다.
- 숨겨 둔 원본 Renderer를 켜면 테마 그림과 겹쳐 보일 수 있다. 물리 컴포넌트를 끄는 것과 Renderer 표시를 끄는 것은 서로 다르다.
- 붕괴 발판의 제한 시간 게이지 등 기존 동작용 자식은 유지한다.
- 배경은 **`05 테마 배경 · 월드 고정`** 계층에서 확인한다. 월드 높이에 따라 쌓인 구름·안개·먼 건축 그림이며, 카메라에 붙어 이동하는 한 장의 배경이 아니다.

### 비교 이미지의 공통 카메라

갤러리는 **1280×720, 정사영 크기 9, 카메라 X=0**으로 같은 구간을 본다. 하층 Y=7m, 중층 Y=87m, 상층 Y=169m다. 원래 게임 카메라를 이동시켜 저장하는 대신 임시 캡처 카메라를 사용한다.

Unity 비교 창의 출발·중간·정상 버튼도 같은 높이를 보며 Scene 창의 보기 크기는 15다. 이 값은 편집 화면 탐색용이며, 실제 플레이 카메라의 낙하 추적·예약 재생 규칙을 바꾸지 않는다.
